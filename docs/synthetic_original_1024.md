# Synthetic master protocol

See [the dataset](dataset.md) for the clean sequence and sampling,
[the experiment protocol](experiment_protocol.md) for learning and evaluation,
and [reproducibility](reproducibility.md) for commands and saved results.

`configs/synthetic_original_1024.json` retains the original 128-grid, depth-two
configuration. The current public configurations are `synthetic_256.json` and
`synthetic_512.json`, each with at most one spatial split. Configuration names
do not override their recorded settings.
